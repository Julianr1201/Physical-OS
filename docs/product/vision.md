# Vision

Physical OS is a vendor-neutral way to observe and orchestrate a physical place. A home is the first place. The same registry, capabilities, events, automations, policy and audit should later serve a garden, a building, or a robot without turning those domains into the same product.

The operator stays in control. An automation is a versioned document. A language model may suggest a plan. Execution always passes schema validation, capability matching, authorization, safety policy, and, when required, a person.

Essential control works offline. Cloud services and language models are optional adapters, not the power path.
